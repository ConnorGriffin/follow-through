# Synthetic example: Maya Chen

Maya Chen, Jordan Lee, their work, and every event in this directory are
fictional. These records exist only to demonstrate Follow Through's schemas and
review loop. They are not redacted or adapted personal history.

The central example is a four-day-workweek trial. Maya predicts that protecting
Friday for uninterrupted work will improve deep-work output. The later outcome
shows that the prediction was wrong and deliberately declines to turn one trial
into a permanent belief.
